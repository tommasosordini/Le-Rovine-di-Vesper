# Le Rovine di Vesper

Gioco di ruolo a turni per desktop. Crea un Guerriero o un Mago, supera tre stanze e affronta il Guardiano di Vesper. Puoi salvare tra uno scontro e l'altro.

Serve un JDK 17 e una connessione Internet al primo avvio del Gradle Wrapper. Dalla cartella del progetto, su Linux e macOS:

```sh
./gradlew build
./gradlew run
```

Su Windows, da PowerShell:

```powershell
.\gradlew.bat build
.\gradlew.bat run
```

Per aprirlo in IntelliJ IDEA, seleziona questa cartella con **File → Open** e imposta un JDK 17 per Gradle.

**Uso dell'AI.** Codex è stato utilizzato per la progettazione, la generazione del codice e delle verifiche, e la stesura della documentazione. La dichiarazione dettagliata è nella Wiki del repository.
